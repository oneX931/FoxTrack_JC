# FoxTrack (Jetpack Compose)

Android-версия трекера видеоигр FoxTrack, полностью переписанная на Jetpack Compose. Приложение работает автономно: сервер не нужен.

## Возможности

- Регистрация и вход, аккаунты хранятся на устройстве (хеш пароля PBKDF2), сессия сохраняется на 30 дней
- Поиск игр в TheGamesDB; издания и версии одной игры для разных платформ объединяются в одну карточку
- Библиотека с обложками, поиском по названию и фильтрами по статусу и платформе
- Статусы «Хочу пройти», «Играю», «Пройдена»; для пройденных игр доступны оценка 1–10 и отзыв
- Несколько платформ прохождения у одной игры
- Профиль: имя, почта, пароль, аватар
- Светлая и тёмная темы, русский и английский языки

## Запуск

1. Откройте папку проекта в Android Studio и дождитесь синхронизации Gradle.
2. Получите ключ API на thegamesdb.net и передайте его одним из способов:
   - добавьте строку `TGDB_API_KEY=ваш_ключ` в файл `local.properties` рядом с `sdk.dir` и пересоберите проект;
   - либо введите ключ в приложении: меню аватара → Настройки → вкладка «Данные».
3. Запустите конфигурацию `app` на устройстве или эмуляторе (Android 12L / API 32 и выше).

Без ключа вход, библиотека и настройки работают, но поиск игр сообщит, что ключ не указан.

## Что заменило серверную часть

| Было (веб + сервер)              | Стало (приложение)                                      |
|----------------------------------|---------------------------------------------------------|
| SQLite на сервере                | SQLite на устройстве (`FoxDatabase`)                    |
| Express-маршруты                 | Репозитории `AuthRepository`, `LibraryRepository`, `SearchRepository` |
| Прокси к TheGamesDB и его кэш    | `TgdbClient` с теми же кэшами (словари 30 дней, поиск 10 минут) |
| Группировка изданий на сервере   | `domain/Titles.kt` (перенос `titles.js`)                |
| Cookie-сессии                    | `SessionManager` и `SettingsStore`                      |
| Argon2id                         | PBKDF2 (Argon2 нет в Android SDK)                       |

## Структура

```
app/src/main/java/com/example/foxtrack/
  domain/        модели, валидация, названия и группировка, даты, платформы
  data/          SQLite, TheGamesDB, репозитории, настройки, хеширование
  ui/theme/      цвета, шрифты, формы
  ui/components/ общие компоненты Compose
  ui/viewmodel/  ViewModel и состояния экранов
  ui/screens/    вход, библиотека, поиск, игра, настройки
  ui/AppRoot.kt  корень приложения, навигация, шапка, нижняя панель
```

## Заметки

- Строки лежат в `res/values` (русский) и `res/values-en` (английский). Язык переключается пересозданием Activity.
- Пиксельный шрифт Geist Pixel не содержит кириллицу, поэтому русские заголовки набираются Geist.
- Иконки Lucide конвертированы в векторные drawable, шрифты Geist и значки распространяются по своим лицензиям (см. `app/src/main/assets/licenses`).
